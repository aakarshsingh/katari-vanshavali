Controls

  • 🔒 Lock (toolbar) — tree is locked (view-only) by default; click to unlock and edit
  • Scroll — pan  ·  Ctrl + Scroll — zoom
  • Search (toolbar) — find anyone by English or Hindi name
  • Hover a card (locked) — highlights the lineage up to the root
  • −/+ at a card's base — collapse / expand that branch
  • Minimap (bottom-right) — drag the box to pan large trees
  • When unlocked:
  • Click a card or hover ✎ — edit (each spouse has its own ✎)
  • + (hover a card) — add a child
  • Right-click a card — menu: add / edit / delete
  • Add (toolbar) — add anyone, pick a parent from the dropdown
  • Tick Married to add a spouse; untick Living to record a death year
